# US Dividend WHT by Country

Dividend withholding tax rates applied by the United States to nonresident
recipients, by country of tax residence. 84 rows: 65 treaty jurisdictions
and 19 non-treaty entries.

Canonical source page, methodology, and change log:
https://www.divatlas.com/us-dividend-tax-rates-by-country/

## Files

- `us-dividend-wht-2026.csv` / `.json` — 2026 edition snapshot
- `us-dividend-wht-latest.csv` / `.json` — aliases tracking the latest edition
- `rates-table.html` — the full table as a static page
- `README.txt` — field definitions and edition rules
